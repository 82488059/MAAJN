# 找温无双

本页说明界面任务「找温无双」。入口在 `assets/interface.json`，节点在 `assets/resource/pipeline/find_wen_task.json`，入口名 `找温无双`。可单独跑；也可由 [一条龙](一条龙.md) 在 [返回百业](返回百业.md) 成功后通过锚点 `回百业_结束后` 调用。一条龙寻到人后经锚点 `找温无双_结束后` 再进 [退出游戏](退出游戏.md)（暂空转）。

坐标按控制器缩放到短边 720 后的 **1280×720** 图计算。

## 目标

返回驻地之后，人在门口，脸朝正房。沿镜头前方走进正房，直到屏幕右侧出现对话条「温无双」。

摇杆方向跟着镜头。落点或朝向变了，这条线会走偏。

## 步骤

0. 入口同帧：先 OCR 右侧是否已有「温无双」对话（`找温_已见对话`）→ 有则直接结束；**没有**则进 `找温_唤起摇杆`。二者必须都写在入口 `next` 里。若只把「唤起摇杆」写在 OCR 节点的 `on_error`，门口认不到对话时**进不了该节点**，`on_error` 不会跑，入口 timeout 后直接 `找温无双_结束失败`（人站在门口不动）。
1. **先点按唤起摇杆** `(200, 480)`，再 **持续朝前 10 秒**（`找温_直走`）。从 `(200, 480)` 滑到 `(200, 240)`：`duration` **700** 毫秒推满（≤300 易被收成点击，人站着空等），`end_hold` **10000** 毫秒按住朝前。不要把 `duration` 写成 10 秒。过院门、趟过水渠。水可以过。
2. **往右 0.7 秒**（仅此一次右移），从 `(180, 400)` 滑到 `(360, 400)`，正对门口。
3. **朝前 1.2 秒**走进正房。
4. **再朝前 1 秒**靠近柜台（**不再二次右移**）。
5. OCR 右侧对话条「温无双」，ROI `[730, 380, 220, 70]`，阈值 0.5。与 [自动买药](自动买药.md) 要点的是同一条。**只认不点**。
6. 没认到就再朝前 1 秒，然后再认。仍没有则 `找温无双_结束失败`，停在当前画面。

## 与一条龙的衔接

| 项 | 说明 |
| --- | --- |
| 触发 | 一条龙入口锚点 `"回百业_结束后": "找温无双"` |
| 时机 | 返回驻地成功、`回百业_结束` 之后。人在门口，脸朝正房 |
| 单独「返回百业」 | 不设该锚点，落到 `回百业_收工` |
| 返回失败 | `回百业_结束失败` 不进本任务 |
| 寻到之后 | 仅 OCR 命中对话条进入 `找温无双_结束` 后：一条龙有 `"找温无双_结束后": "退出游戏"` 才进 [退出游戏](退出游戏.md)；未设则 `找温无双_收工`。不点对话 |
| 寻失败 | `找温无双_结束失败`，**绝不**进退出游戏 |
| 一条龙前序 | 买药→离开→炼药→钱袋→返回须都成功才会进本任务；本任务再认出对话条后才退出游戏 |

## 安全原则

- 不点「温无双」。单独跑不点「退出」、不打开菜单；一条龙把退出交给 [退出游戏](退出游戏.md)（当前空转也不点）。
- 直走会贴在门左侧，必须先往右再进门；进门后不要再右移。
- 对话条出现就停，不再往前走。
