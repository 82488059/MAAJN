# 买药炼药一条龙

本页说明界面任务「买药炼药一条龙」：**先跑自动买药，三家买齐后回到主菜单（关货运再 [离开百业](离开百业.md)），再跑炼药，再买钱袋，买钱成功后返回百业，再找温无双**。入口与选项在 `assets/interface.json`；买药与一条龙入口在 `assets/resource/pipeline/medicine_task.json`。离开百业在 `leave_baiye_task.json`。炼药入口名必须是 `炼药`。衔接用锚点 `离开百业_结束后`、`钱袋_结束后`、`回百业_结束后`。

买药细节见 [自动买药](自动买药.md)。离开百业见 [离开百业](离开百业.md)。炼药细节见 [炼药](炼药.md)。买钱袋见 [买钱袋](买钱袋.md)。返回百业见 [返回百业](返回百业.md)。找人见 [找温无双](找温无双.md)。存放仍由买药在需要时调用，见 [存放原料](存放原料.md)。

## 功能概述

角色已站在温无双旁时，一条龙依次做：

1. 跑 [自动买药](自动买药.md)。三家都买成后由该任务的 `买药_回到主菜单` 关货运。
2. 接着 [离开百业](离开百业.md)。不进 `买药_结束`，改走 `炼药`。
3. 跑 [炼药](炼药.md)。退出界面后续 [买钱袋](买钱袋.md)。
4. 买钱成功回到主界面后，走 [返回百业](返回百业.md)。
5. 返回驻地成功后，走 [找温无双](找温无双.md)。寻到右侧对话条就停，不点对话。

未买齐三家时，行为与单独「自动买药」相同：走「买一种提交一种」或第三轮失败，**不关货运去离开，也不进炼药**。买药强制结束、提交未满五停在货运，同样不进炼药。离开百业失败（`离开百业_结束失败`）不进炼药。买钱失败（`钱袋_结束失败`）不返回百业。返回百业失败（`回百业_结束失败`）不找人。

## 前置条件

- 与 [自动买药](自动买药.md) 相同：站在温无双旁，短边 720，OCR 模型已就绪。
- 离开百业成功后，画面上应出现对话条「炼药」。离开后到炼药这一段不寻路；若离开后没有炼药对话，由炼药任务自己失败或安全退出，买药侧不再补点。
- 返回驻地成功后走 [找温无双](找温无双.md)。人应在门口、脸朝正房。寻到对话条后停住，不点。
- 炼药材料是否够用仍按炼药页：材料不足分支尚未实现。

## 衔接锚点

| 入口 | `离开百业_结束后` | `钱袋_结束后` | `回百业_结束后` |
| --- | --- | --- | --- |
| `自动买药` | `买药_结束` | （不涉及） | （不涉及） |
| `买药炼药一条龙` | `炼药` | `返回百业` | `找温无双` |
| 单独 `离开百业` | 不设锚点 → `离开百业_结束` | — | — |
| 单独 `买钱袋` / `炼药` | — | 不设锚点 → `钱袋_收工` | — |
| 单独 `返回百业` | — | — | 不设锚点 → `回百业_收工` |

约定：

1. `自动买药` 的 `anchor` 含 `"离开百业_结束后": "买药_结束"`。现有六项未买 / 买齐锚点不变。
2. `买药_确认已离开` 的 `next` 是入口 `离开百业`（先关货运，再点驻地退出）。主菜单出现并且右上已经没有「退出」后，走锚点 `离开百业_结束后`。
3. 入口 `买药炼药一条龙`：`离开百业_结束后`=`炼药`，`钱袋_结束后`=`返回百业`，`回百业_结束后`=`找温无双`。
4. `钱袋_结束` 走锚点 `钱袋_结束后`；买钱失败节点不走该锚点。`回百业_结束` 走锚点 `回百业_结束后`；`回百业_结束失败` 不找人。
5. `买药_结束`、`买药_强制结束`、`买药_提交未满五` 等仍直接结束或停在货运，**不要**改成走 `离开百业`。

## 界面任务与选项

| 项 | 说明 |

## 与两边任务的边界

- **不复制**买药 / 离开百业 / 炼药 / 买钱袋 / 返回百业 / 找温无双的内部节点；一条龙只改入口锚点。
- 炼药仍不调用买药 / 存放锚点，也不在失败时改写「已买成」标记。
- 一条龙任务过程中，已买标记与单独买药相同：只在本次任务存活。
