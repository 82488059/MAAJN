## 调试时值得核对的坐标

`display_short_side` 是 720。默认 ROI `[150, 30, 970, 670]` 覆盖到横坐标 1120、纵坐标 700，`回主界面` 和 `点击...` 的 ROI 从 `x = 1180` 起。这是横屏、短边 720（约 1280×720）上的坐标。

作者本地 MuMu 记录的分辨率是 900×1600 竖屏。竖屏按短边 720 缩放后宽度是 720，`x = 1180` 会落在画面外面。流水线 JSON 里没有旋转或另一套分辨率的配置，接上模拟器后需要核对截图方向是不是这套 ROI 所假设的横屏。
