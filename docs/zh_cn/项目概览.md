# 项目概览

MaaJNBJ 是基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 官方模板 MaaPracticeBoilerplate 的安卓图像识别自动化项目。界面协议为 Project Interface V2，控制器只有 Adb。任务逻辑写在 `assets/resource/pipeline/*.json`，通用 UI 读 `assets/interface.json` 来展示任务列表。

`interface.json` 里的项目字段：

| 字段 | 当前值 |
| --- | --- |
| `interface_version` | `2` |
| `name` | `MaaJNBJ` |
| `license` | `MIT`（与根目录 `LICENSE` 一致） |
| `version` | `1.0.0`（源码中的值；打包时 `tools/install.py` 会改写安装目录里的副本） |
| `description` | `这是一个使用 MaaFramework 创建的新项目。` |
| `contact` | `QQ群: 123456789` |
| `welcome` | `首次使用！欢迎使用 MAA!` |
| `github` | `https://github.com/MaaXYZ/MaaPracticeBoilerplate` |

`description`、`contact`、`welcome` 和 `github` 仍是模板占位，详见 [模板遗留与待改进](模板遗留与待改进.md)。`mirrorchyan_rid` 被注释掉，默认不走 Mirror酱更新。

## 控制器与资源

控制器只有一项：

- 名称 `安卓端`
- 类型 `Adb`
- `display_short_side` 为 `720`，注释写的是「默认缩放分辨率的短边长度」

识别前画面会按短边 720 缩放，流水线里的 ROI 和模板图都在这个坐标系里。模板图应是缩放到 720p 之后的裁剪。

资源只有一项：

- 名称 `官服`
- 路径 `./resource`，相对 `interface.json` 所在目录

源码里也就是 `assets/resource`。打包后 `interface.json` 和 `resource/` 都在安装目录根下，相对关系不变。这里没有第二套资源，名称「官服」不会在代码里切换服务器。

## 界面任务

`task` 数组目前有 4 项。`name` 是界面上的名字，`entry` 是流水线入口节点名。四项的两个字段相同，也没有 `option` 或 `pipeline_override`。

| 界面任务 | 入口节点 | 定义文件 |
| --- | --- | --- |
| 无限水井 | `无限水井` | `assets/resource/pipeline/well_task.json` |
| 修改为地基模式 | `修改为地基模式` | `assets/resource/pipeline/public_task.json` |
| 无限集英 | `无限集英` | `assets/resource/pipeline/yysls_task.json` |
| 无限太极 | `无限太极` | `assets/resource/pipeline/yysls_task.json` |

`vegetable_task.json` 里有完整的「无限蔬菜」链路，`verification_task.json` 里有机关破解，但它们没有登记到 `interface.json` 的 `task` 里。机关破解会被「处理异常」间接调用；无限蔬菜没有入口连上来。

## 目录结构

```text
.
├── assets/
│   ├── interface.json                 # 通用 UI：控制器、资源、任务入口
│   ├── MaaCommonAssets/               # 子模块，提供 OCR 模型来源（见 .gitmodules）
│   └── resource/
│       ├── default_pipeline.json      # 所有节点的默认 ROI、超时、阈值
│       ├── image/                     # 模板图，相对路径写在 pipeline 的 template 字段
│       ├── model/                     # 运行时 OCR 放在 model/ocr/，该目录被 gitignore
│       └── pipeline/
│           ├── public_task.json       # 公共按钮，以及「修改为地基模式」
│           ├── well_task.json         # 无限水井
│           ├── vegetable_task.json    # 无限蔬菜（未登记到界面）
│           ├── verification_task.json # 破解机关
│           └── yysls_task.json        # 无限集英、无限太极
├── agent/                             # Python 自定义动作/识别示例，当前未启用
│   ├── main.py
│   ├── my_action.py
│   └── my_reco.py
├── tools/
│   ├── configure.py                   # 从子模块复制 OCR 模型
│   ├── install.py                     # 组装 install/ 目录
│   ├── validate_schema.py             # 用 deps/tools 下的 schema 校验
│   └── requirements.txt               # 仅 json-with-comments
├── deps/tools/                        # MaaFramework 的 JSON Schema
├── check_resource.py                  # 用 maafw 加载资源包
├── .github/workflows/                 # 检查、打包发布、schema 同步
└── docs/zh_cn/                        # 本说明
```

`pipeline/` 下所有 JSON 会合成一张节点表。节点名全局唯一，当前 5 个文件之间没有重名。文件名以 `.` 开头的 JSON 不会被框架加载；以 `$` 开头的根字段不会被解析。本仓库的流水线文件都用了 `//` 注释，按 JSONC 读取。`.vscode/settings.json` 把 `assets/**/*.json` 关联成 `jsonc`。

## 自定义 Agent

`interface.json` 里的 `agent` 配置整段被注释：

```jsonc
// "agent": {
//     "child_exec": "python",
//     "child_args": [
//         "./agent/main.py"
//     ]
// },
```

因此运行任务时不会启动 `agent/main.py`。该目录仍是模板示例：

- `main.py` 用命令行最后一个参数作为 `socket_id`，调用 `AgentServer.start_up` / `join` / `shut_down`
- `my_action.py` 注册自定义动作 `my_action_111`，打印一行后返回成功
- `my_reco.py` 注册自定义识别 `my_reco_222`，示例里调用了节点 `MyCustomOCR`

现有 pipeline 没有 `Custom` 识别或动作，也没有名为 `MyCustomOCR` 的节点。

## 模板图

图片在 `assets/resource/image/`，`template` 填相对这个目录的路径。流水线实际引用的图：

| 路径 | 使用它的节点 |
| --- | --- |
| `井小.png`、`井大.png` | `寻找水井`、`查找水井` |
| `vegetable/菜小.png`、`vegetable/菜大.png` | `寻找蔬菜`、`查找蔬菜` |
| `印.png` | `修改为地基模式`、`印` |
| `地基.png` | `是地基` |
| `非地基.png` | `不是地基` |
| `20.png` | `20` |
| `重试.png` | `重试` |
| `更多.png` | `回主界面`、`点击...` |
| `设置.png` | `关闭更多` |
| `撤销.png` | `撤销` |
| `完成.png` | `完成布局` |
| `改布局.png` | `关闭改布局` |
| `x.png` | `x` |
| `机关/1.png` … `机关/12.png` | `机关1` … `机关12` |

其余图片在仓库里，但没有任何节点的 `template` 指向它们：`empty.png`（文件只有 1 字节）、`丢弃.png`、`人.png`、`免费完成.png`、`垃圾桶.png`、`搜索.png`、`显示地基.png`、`显示建筑.png`、`铜钱生产完成.png`。`免费完成` 节点认的是文字「免费」，用的不是 `免费完成.png`。
