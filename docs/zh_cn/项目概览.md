# 项目概览

MAAJN 是基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 官方模板 MaaPracticeBoilerplate 的安卓图像识别自动化项目。界面协议为 Project Interface V2，控制器只有 Adb。任务逻辑写在 `assets/resource/pipeline/*.json`，通用 UI 读 `assets/interface.json` 来展示任务列表。部分任务（自动炼药、自动买钱）依赖 Python Agent 自定义动作。

`interface.json` 里的项目字段：

| 字段 | 当前值 |
| --- | --- |
| `interface_version` | `2` |
| `name` | `MAAJN` |
| `license` | `MIT`（与根目录 `LICENSE` 一致） |
| `version` | `1.0.2`（源码中的值；打包时 `tools/install.py` 会改写安装目录里的副本） |
| `description` | `这是一个使用 MaaFramework 创建的新项目。` |
| `contact` | `QQ群: 123456789` |
| `welcome` | `首次使用！欢迎使用 MAA!` |
| `github` | `https://github.com/82488059/MAAJN` |

`description`、`contact`、`welcome` 仍是模板占位，详见 [模板遗留与待改进](模板遗留与待改进.md)。`mirrorchyan_rid` 被注释掉，默认不走 Mirror酱更新。

## 控制器与资源

控制器只有一项：

- 名称 `安卓端`
- 类型 `Adb`
- `display_short_side` 为 `720`，注释写的是「默认缩放分辨率的短边长度」

识别前画面会按短边 720 缩放，流水线里的 ROI 和模板图都在这个坐标系里。模板图应是缩放到 720p 之后的裁剪。

资源只有一项：

- 名称 `官服`
- 路径 `./resource`，相对 `interface.json` 所在目录

源码里也就是 `assets/resource`。打包后 `interface.json` 和 `resource/` 都在安装目录根下，相对关系不变。这里没有第二套资源，名称「官服」不会在代码里切换服务器。

```text
.
├── assets/
│   ├── interface.json                 # 通用 UI：控制器、资源、Agent、任务入口与选项
│   ├── MaaCommonAssets/               # 子模块，提供 OCR 模型来源（见 .gitmodules）
│   └── resource/
│       ├── default_pipeline.json      # 所有节点的默认 ROI、超时、阈值
│       ├── image/                     # 模板图（含 medicine/、moneybag/、storage/、vegetable/、机关/ 等）
│       ├── model/                     # 运行时 OCR 放在 model/ocr/，该目录被 gitignore
│       └── pipeline/
│           ├── public_task.json       # 公共按钮、地基模式、处理异常
│           ├── well_task.json         # 无限水井
│           ├── vegetable_task.json    # 无限蔬菜（未登记到界面）
│           ├── verification_task.json # 破解机关
│           ├── yysls_task.json        # 无限集英、无限太极
│           ├── medicine_task.json     # 自动买药、一条龙
│           ├── storage_task.json      # 存放原料
│           ├── leave_baiye_task.json  # 离开百业
│           ├── alchemy_task.json      # 炼药
│           ├── moneybag_task.json     # 自动买钱
│           ├── return_baiye_task.json # 返回百业
│           ├── find_wen_task.json     # 找温无双
│           └── exit_game_task.json    # 退出游戏（暂空转）
├── agent/                             # Python Agent（已启用）
│   ├── main.py                        # 启动 AgentServer，加载下列模块
│   ├── alchemy_action.py              # 炼药自定义动作
│   ├── moneybag_action.py             # 钱袋自定义动作
│   ├── my_action.py                   # 模板示例动作
│   └── my_reco.py                     # 模板示例识别
├── tools/
│   ├── configure.py                   # 从子模块复制 OCR 模型
│   ├── install.py                     # 组装 install/ 目录
│   ├── validate_schema.py             # 用 deps/tools 下的 schema 校验
│   └── requirements.txt               # 仅 json-with-comments
├── deps/tools/                        # MaaFramework 的 JSON Schema
├── check_resource.py                  # 用 maafw 加载资源包
```

`pipeline/` 下所有 JSON 会合成一张节点表。节点名全局唯一。文件名以 `.` 开头的 JSON 不会被框架加载；以 `$` 开头的根字段不会被解析。本仓库的流水线文件都用了 `//` 注释，按 JSONC 读取。`.vscode/settings.json` 把 `assets/**/*.json` 关联成 `jsonc`。

## 自定义 Agent

`interface.json` 已启用 Agent：

```jsonc
"agent": {
    "child_exec": "python",
    "child_args": [
        "./agent/main.py"
    ]
},
```

运行任务时会启动 `agent/main.py`。`main.py` 导入 `alchemy_action`、`moneybag_action`、以及模板示例 `my_action` / `my_reco`。

当前注册的自定义动作：

| 动作名 | 文件 | 用途 |
| --- | --- | --- |
| `炼药_算量并输入` | `alchemy_action.py` | 炼药算量与小键盘输入 |
| `炼药_耗尽则退出` | `alchemy_action.py` | 炼药循环退出判定 |
| `钱袋_判定是否买金丝` | `moneybag_action.py` | 按体力决定是否买金丝钱袋 |
| `my_action_111` | `my_action.py` | 模板示例（流水线未引用） |

模板示例识别 `my_reco_222`（`my_reco.py`）调用的节点名 `MyCustomOCR` 在 pipeline 中不存在，流水线也未引用它。

自动炼药、自动买钱、**一条龙**必须能连上 Agent；其余界面任务不依赖自定义动作。Agent 起不来时 MFA 会报「连接重试 / Agent启动失败」，常见原因是本机 `python` 未安装 `maafw`（`No module named 'maa'`）。安装与核对见 [本地开发与调试](本地开发与调试.md) 的「Python Agent」小节。细节见对应专文。
